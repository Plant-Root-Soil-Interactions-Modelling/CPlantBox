# SIMPLACE-CPlantBox

This example works with:
- SIMPLACE v5.0

The coupling is controlled by a single python script which was adapted from a previous SIMPLACE-CRootBox developed by Gunther Kraus, Murilo Vianna and Sabine Seidel: 
- https://doi.org/10.3389/fpls.2022.865188

## Running an example for SIMPLACE-CPlantBox:

```
cd ~/workspace/simplace_wrapper/python_simplace/trunk/PyPlantBox/misc/
python example_simplace_cplantbox.py
```
